# Docker Assignment

## Overview
This project focuses on Docker fundamentals, containerization concepts, and deployment practices used in DevOps environments.

---

## Objectives
- Understand Docker containerization
- Build and manage Docker images
- Run applications inside containers
- Practice Linux-based deployment workflows

---

## Technologies Used
- Docker
- Linux
- Python
- GitHub

---

## Docker Concepts Practiced
- Docker images
- Docker containers
- Docker commands
- Container lifecycle management
- Application deployment basics

---

## Example Commands

```bash
docker build -t myapp .
docker run -p 5000:5000 myapp
docker ps
docker logs container_id
```
